Archivos del flujo anterior, conservados como referencia.

- procesar.php: generación a partir de Excel y ZPL subidos.
- descargar.php y Plantilla.xlsx: plantilla Excel anterior.
- imprimir.php: envío de archivos acumulados en uploads.
- src/: biblioteca Spout para leer Excel.
- plantillas/: diseño de ejemplo del primer prototipo.
- php.ini.txt: copia de configuración PHP.
- uploads/: etiquetas históricas, conservadas sin cambios.

La aplicación actual no depende de estos archivos. .htaccess bloquea su acceso web para evitar ejecutar accidentalmente los scripts antiguos.
